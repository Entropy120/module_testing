# Отчет по КТ № 10: Кроссбраузерное и адаптивное тестирование

## 1. Выбор веб-приложения
**Сайт:** SauceDemo (https://www.saucedemo.com/)
**Обоснование:** Сайт имеет ярко выраженный адаптивный дизайн (изменение сетки, скрытие/появление меню-бургера на мобильных устройствах).

## 2. Методика тестирования
Тестирование проводилось автоматизированным методом с использованием Selenium WebDriver и параметризации в Pytest. Были сымитированы следующие устройства:
- **Desktop** (1920x1080)
- **Tablet** (768x1024)
- **Mobile** (375x812)

Для каждого разрешения выполнялись:
1. Открытие страницы авторизации.
2. Создание скриншота экрана (сохранен в папке `screenshots/`).
3. Проверка видимости ключевых элементов интерфейса (поля ввода логина и кнопки "Login").

## 3. Результаты тестирования и обнаруженные проблемы
Автоматизированные тесты во всех трех разрешениях прошли успешно (PASSED). Основные элементы (формы) остаются доступными.

**Визуальный анализ (по скриншотам):**
В ходе ручного анализа скриншотов были выявлены следующие особенности адаптивности:
1. **Планшет (768px):** Поля ввода и кнопка "Login" растягиваются на 100% ширины контейнера, что визуально выглядит хорошо, но шрифт placeholder'а ("Username") кажется слишком мелким для планшета.
2. **Мобильный (375px):** Логотип Swag Labs становится слишком крупным и занимает почти всю ширину экрана, из-за чего форма логина смещается вниз (требуется скроллинг). 

**Рекомендации по улучшению:**
- Для мобильной версии (менее 400px) рекомендуется уменьшить размер логотипа (использовать медиа-запрос `@media (max-width: 400px)`).
- Увеличить размер шрифта в полях ввода (минимум 16px), чтобы предотвратить нежелательный автозум на мобильных устройствах iOS (Safari).

## 4. Отчетность
Согласно требованиям, был использован плагин `pytest-html`. 
Сгенерирован итоговый отчет `report.html`, содержащий статусы тестов, время выполнения и древовидную структуру. Ошибок, приводящих к падению тестов (Failed), не обнаружено.

## 5. Выводы
Приложение SauceDemo успешно адаптируется под разные разрешения экрана. Кроссбраузерное тестирование (в связке с параметризацией размеров окна) позволяет быстро выявлять UI-дефекты даже без использования дорогостоящих облачных ферм устройств (BrowserStack).
