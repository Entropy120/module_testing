# Отчет по тестированию мобильного приложения

## 1. Описание приложения и стратегия
**Выбранное приложение:** SauceLabs My Demo App (Android) — тренировочное приложение, имитирующее интернет-магазин (авторизация, каталог, корзина).
**Специфика платформы (Android):** Тестирование проводится с использованием драйвера `UiAutomator2`. Основной упор сделан на поиск элементов через `resource-id` (для надежности) и явные ожидания (`WebDriverWait`), так как мобильные приложения часто подгружают элементы с задержкой.
**Типы тестирования:** Функциональное, UI/UX (удобство использования), Негативное.

## 2. Тест-план
**Цель:** Проверить корректность работы авторизации и добавления товаров в корзину.
**Критерии начала (Entry):** Приложение установлено на эмуляторе Android (API 30+). Appium Server запущен.
**Критерии завершения (Exit):** Выполнены все тест-кейсы. Критические дефекты (Blocker/Critical) отсутствуют.

## 4. Отчет о дефекте (Баг-репорт)
- **ID:** BUG-MOB-001
- **Summary:** Кнопка "Add to Cart" перекрывает цену товара на устройствах с маленьким экраном.
- **Environment:** Эмулятор Pixel 4 (Android 11), разрешение 1080x2280.
- **Шаги для воспроизведения:** Открыть карточку товара на устройстве с диагональю до 5.5 дюймов.
- **Ожидаемый результат:** Элементы не пересекаются, интерфейс адаптивный.
- **Фактический результат:** Кнопка добавления в корзину накладывается на текст цены, делая его нечитаемым.
- **Приоритет:** Major. **Серьезность:** UI/UX.
- **Рекомендация:** Использовать `ConstraintLayout` во Flutter/Android для адаптивного позиционирования.

## 5. Итоговый анализ
Функционал работает стабильно. Найден 1 UI-дефект. Рекомендуется внедрить в CI/CD (Jenkins/GitHub Actions) запуск Appium-тестов на облачных фермах (например, BrowserStack) для покрытия матрицы реальных устройств.
