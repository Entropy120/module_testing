# Отчет по практической работе: Паттерн PageObject

## 1. Описание тестируемого приложения
В качестве тестируемого приложения выбран тренировочный сайт **The Internet** (https://the-internet.herokuapp.com/). 
Тестируемый функционал: страница авторизации (Login Page).

## 2. Перечень тестовых сценариев
- **TS-01**: Успешная авторизация с валидными данными (позитивный сценарий).
- **TS-02**: Авторизация с неверным паролем (негативный сценарий, проверка текста ошибки).

## 3. Код автоматизированных тестов
В ходе работы был реализован паттерн **PageObject**:
- Создан базовый класс `BasePage`, содержащий общие методы и настройку явных ожиданий (`WebDriverWait`).
- Создан класс `LoginPage`, инкапсулирующий локаторы страницы и методы взаимодействия (ввод логина, пароля, клик).
- Методы возвращают `self` для реализации цепочек вызовов.
- Тесты используют фикстуру `browser` из `conftest.py` с возможностью выбора браузера через аргумент `--browser`.
