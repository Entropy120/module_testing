## 3. Отчет об ошибках (Кроссплатформенные дефекты)
**Дефект 1: Некорректное отображение Dropdown в Safari (macOS)**
- **Описание:** При открытии страницы `/dropdown` в Safari выпадающий список `<select>` имеет дефолтную высоту, из-за чего текст "Please select an option" обрезается снизу на 2-3 пикселя.
- **Шаги воспроизведения:** Открыть сайт в Safari -> Перейти в Dropdown List -> Взглянуть на стрелку и текст.
- **Ожидаемый результат:** Элемент отображается полностью.
- **Фактический результат:** Текст обрезан (см. скриншот `safari_dropdown_bug.png`).
- **Предполагаемая причина:** Различия в User-Agent стилях (webkit) для тега `<select>`. Необходимо добавить `-webkit-appearance: none` и кастомные стили.

**Дефект 2: Проблема с зумом на мобильном Chrome**
- **Описание:** На Android при открытии страницы `/iframe` при попытке ввести текст в редактор TinyMCE страница автоматически зумится, ломая верстку.
- **Ожидаемый результат:** Масштабирование остается стандартным.
- **Фактический результат:** Увеличение интерфейса.
- **Причина:** В мета-теге `viewport` отсутствует `user-scalable=no` или размер шрифта в input меньше 16px (вызывает авто-зум в мобильных браузерах).

## 4. Вывод
Приложение в целом стабильно. Выявлена 1 UI-ошибка (Safari) и 1 поведенческая на мобильных устройствах (автозум).
